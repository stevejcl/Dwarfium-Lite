🌌 Astro Dwarf Session

Automatisation, suivi et contrôle multi-télescopes pour Dwarf II, Dwarf 3 et Dwarf Mini

📌 À propos du projet

Astro Dwarf Session est une application web locale moderne et légère développée avec NiceGUI. Elle permet de piloter, surveiller et automatiser des sessions d'imagerie astronomique pour l'ensemble de la gamme de smart telescopes Dwarf.

L'application s'exécute localement et s'utilise aussi bien depuis une fenêtre de bureau native que depuis un navigateur sur PC, smartphone ou tablette sur le même réseau.

✨ Fonctionnalités clés

  • 🎛️ Dashboard « Mission Control » Multi-Télescopes : Suivez et contrôlez plusieurs Dwarf en parallèle (statut, batterie, température, stockage, progression des captures et aperçus en direct).
  • 🗓️ Gestion Centralisée des Séquences : Une page dédiée répertorie l'ensemble de vos séquences d'imagerie, regroupant aussi bien les programmes créés sur l'outil que les plannings natifs du firmware.
  • 🔄 Synchro des Plannings Natifs (Firmware) : Synchronisez et surveillez la planification interne du Dwarf (statuts en direct : planned, in progress, completed, expired, progression par cible, suppression ou mise en attente hors-ligne).
  • 📡 Connexion & Appairage Flexibles : Appairage Bluetooth (BLE) direct ou configuration manuelle par IP/UID sans Bluetooth.
  • 📍 Gestion des Sites : Associez réseau Wi-Fi et coordonnées géographiques sous forme de "Sites" réutilisables.
  • 🤖 Programmation & Séquençage Automatique : Créez des séquences complètes (GoTo, calibration, résolution EQ, réglages caméra, captures, mosaïques) exécutables immédiatement ou programmables.
  • ⚖️ Répartition automatique des cibles : Envoi automatique des cibles vers les télescopes disponibles du même modèle.
  • 🌌 Planificateur de Mosaïque Voie Lactée : Carte du ciel adaptative selon le crépuscule, contrôle d'impact lunaire et découpage en tuiles.
  • 🖼️ Explorateur de Sessions Astro : Galerie photo des sessions stockées sur l'appareil avec leurs métadonnées (exposition, gain, filtre IR).
  • 👀 Mode Spectateur (/watch) : Mode lecture seule sécurisé pour partager le flux en direct sur le réseau local sans risque de modification.
  • 📱 Support PWA : S'installe directement sur l'écran d'accueil de votre smartphone ou tablette.

🚀 Installation & Démarrage rapide

Prérequis : Python 3.10+ (Windows, macOS, Linux)

# 1. Cloner le dépôt
git clone <URL_DE_VOTRE_REPO>
cd astro_dwarf_session

# 2. Créer et activer l'environnement virtuel
python -m venv myenv
myenv\Scripts\activate  # Windows (ou source myenv/bin/activate sous Linux/macOS)

# 3. Installer les dépendances
python -m pip install -r requirements.txt
python -m pip install -r requirements-local.txt --target .

Lancement de l'application :

# Mode classique (Interface graphique native + serveur web)
python astro_dwarf_ui.py

# Mode serveur uniquement (Headless / Accès distant)
python astro_dwarf_ui.py --no-native

🌌 Astro Dwarf Session

Automated, multi-telescope imaging session manager for Dwarf II, Dwarf 3, and Dwarf Mini

📌 About the Project

Astro Dwarf Session is a lightweight, modern local web application built with NiceGUI. It lets you automate, monitor, and control imaging sessions for the entire family of Dwarf smart telescopes.

It runs locally and can be accessed either as a native desktop window or via a web browser on your PC, smartphone, or tablet on the same local network.

✨ Key Features

  • 🎛️ Multi-Telescope "Mission Control" Dashboard: Monitor and control multiple Dwarfs side-by-side (status, battery, temperature, storage, capture progress, and live stream previews).
  • 🗓️ Centralized Sequence Management: A dedicated page lists all imaging sequences, combining both local app-built programs and native on-device schedules.
  • 🔄 Native Schedule Sync (Firmware): View and monitor the Dwarf's native on-device shooting schedules (live status: planned, in progress, completed, expired, per-target progress, delete, or queue offline).
  • 📡 Flexible Pairing & Connection: Direct Bluetooth (BLE) pairing or a manual IP/UID config wizard when Bluetooth is unavailable.
  • 📍 Site Management: Bundle Wi-Fi credentials and location coordinates into reusable "Sites".
  • 🤖 Program Automation & Scheduling: Build sequences (GoTo, calibration, EQ Solving, camera settings, captures, Mosaics) to run live or schedule for later.
  • ⚖️ Target Load Balancing: Automatically dispatch targets across available telescopes of the same model.
  • 🌌 Milky Way Mosaic Planner: Interactive twilight-aware sky chart, Moon check, and automatic tile grid generation.
  • 🖼️ Astro Session Explorer: Browse real astro sessions directly from device storage with detailed shooting metadata.
  • 👀 Read-Only Watch Mode (/watch): Safe spectator mode to share live previews and session updates across your network without control access.
  • 📱 PWA Support: Install straight to your phone or tablet home screen without a browser search bar.

🚀 Quick Start & Installation

Prerequisites: Python 3.10+ (Windows, macOS, Linux)

# 1. Clone the repository
git clone <YOUR_REPO_URL>
cd astro_dwarf_session

# 2. Create and activate virtual environment
python -m venv myenv
myenv\Scripts\activate  # On Windows (or source myenv/bin/activate on Linux/macOS)

# 3. Install dependencies
python -m pip install -r requirements.txt
python -m pip install -r requirements-local.txt --target .

Running the App:

# Native desktop mode + web server
python astro_dwarf_ui.py

# Web server only (Headless mode)
python astro_dwarf_ui.py --no-native
